# CL-123: Generate the tracker on main, never in a pull request

## Goal

The owner approves each change once. No open PR ever conflicts on `.clutch/TRACKER.md`.

## Context

On 2026-10-31 Brendan re-approved most PRs two or three times. Each PR committed the generated `.clutch/TRACKER.md`, so each merge made every other open PR conflict on it. The fix was a push, and the ruleset (`dismiss_stale_reviews_on_push: true`) then dropped the approval. Once, git merged two PRs' row edits cleanly but left the totals stale, and `main` went red at 5bfa6ce in `check-clutch-issues`.

## Steps

1. Branch `clutch/cl-123-tracker-from-main`.
2. `clutch issues set` and `new` write only the issue file. `clutch issues --check` validates the issue files. `--check --fresh` keeps the old freshness check.
3. `release.yml` regenerates the tracker in the release commit, and commits `chore(tracker): regenerate the tracker` when a merge makes no release.
4. `pr ready` commits only `.clutch/issues`. `pr sync` no longer regenerates the tracker, and takes the base's copy when an older branch still committed it.
5. `.gitattributes` marks the tracker `linguist-generated`, and `clutch.files.yaml` merges `.gitattributes` into projects.
6. Update the deliver and run-lanes skills, `.clutch/README.md`, the CLI README, `checks.md` and `releases.md`.

## Files

- `apps/cli/src/issues-command.ts`, `apps/cli/src/install-template.ts`, `apps/cli/src/init-command.ts`
- `.github/workflows/release.yml`, `.gitattributes`, `clutch.files.yaml`
- `tools/github/branch.ts` and its tests

## Acceptance criteria

- A PR made with `clutch issues new`, `set` and `pr ready` changes no `TRACKER.md`.
- `check-clutch-issues` passes on a PR whose tracker is stale.
- The release commit, or a tracker commit, brings `TRACKER.md` up to date on `main`.

## Verify

```bash
mise exec -- bun test apps/cli/src/issues-command.test.ts tools/github
```

## Notes

- `TRACKER.md` cannot be marked generated in the ruleset: rulesets have no such setting. `.gitattributes` `linguist-generated=true` folds it in PR diffs. The real fix is that PRs stop committing it.
